## Button Legend

### In Chat Header:
- **📞** = Start voice call
- **📹** = Start video call

### During Call:
- **🎤** = Microphone ON (click to mute)
- **🔇** = Microphone MUTED (click to unmute)
- **📹** = Camera ON (click to turn off)
- **🚫** = Camera OFF (click to turn on)
- **📵** = End/Cancel/Decline call

### Incoming Call:
- **📞 (green)** = Accept call
- **📵 (red)** = Decline call

## Step-by-Step: First Voice Call

1. **Open a chat** with your contact
   ```
   [Chats] → Click on "Owen"
   ```

2. **Click the phone icon** 📞
   ```
   Top right corner of chat
   ```

3. **Grant permissions** (first time only)
   ```
   Browser asks: "Allow microphone?"
   Click: "Allow"
   ```

4. **Wait for answer**
   ```
   You'll see: "Calling..."
   Owen sees: "Incoming call..."
   ```

5. **Start talking!**
   ```
   When connected, you'll see: "Connected"
   Timer starts: "00:01", "00:02", etc.
   ```

6. **End call**
   ```
   Click red 📵 button
   ```

## Step-by-Step: First Video Call

1. **Open a chat** with your contact

2. **Click the video icon** 📹

3. **Grant permissions** (first time only)
   ```
   Browser asks: "Allow camera and microphone?"
   Click: "Allow"
   ```

4. **See yourself** in small window
   ```
   Bottom right corner shows your video
   ```

5. **Wait for answer**

6. **See each other!**
   ```
   Main screen: Their video
   Small window: Your video
   ```

7. **Use controls:**
   - 🎤 = Mute/unmute voice
   - 📹 = Turn camera on/off
   - 📵 = End call

## Tips

✅ **Good internet** = Better call quality  
✅ **Headphones** = Prevent echo  
✅ **Good lighting** = Better video (for video calls)  
✅ **Close browser tab** = Automatically ends call  

❌ Don't mute your system volume  
❌ Don't cover your microphone  
❌ Don't use in noisy environments  

## Troubleshooting Quick Fixes

**Can't hear/see them?**
→ Check if they're muted (red button)

**They can't hear/see you?**
→ Check if YOU'RE muted (red button)

**No permissions dialog?**
→ Click 🔒 in address bar → Allow mic/camera

**Call won't connect?**
→ Both users must be online and contacts
